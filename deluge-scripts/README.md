# Deluge Scripts Workspace

This folder contains your local Deluge script development environment, organized to work seamlessly with the **Full Deluge Coding Interface**.

## Quick Start

### 1. Access the Online Interface
- **Main Editor:** https://deluge.zoho.com/tryout
- **Learning Interface:** https://deluge.zoho.com/learndeluge

### 2. Your First Test
1. Open https://deluge.zoho.com/tryout
2. Copy the contents of `basic/hello-world.deluge`
3. Paste into the online editor
4. Click **Execute** to run the script
5. View the output in the results panel

### 3. Practice Scripts

#### Basic Level
- `basic/hello-world.deluge` - Your first Deluge script
- `basic/data-types.deluge` - Working with strings, numbers, lists, and maps

#### Advanced Level  
- `advanced/loops-and-conditions.deluge` - Control flow and data processing

## Workflow

### Testing Process
1. **Write/Edit** scripts locally in this workspace
2. **Copy & Paste** into https://deluge.zoho.com/tryout
3. **Execute** and test in the online interface
4. **Document** results using the test template
5. **Save** improved versions back to your local files

### Directory Structure
```
deluge-scripts/
├── basic/           # Simple scripts for learning
├── advanced/        # Complex scripts and patterns
├── examples/        # Real-world examples (add your own)
├── tests/           # Test results and documentation
└── README.md        # This file
```

## Features of the Online Interface

### ✅ Available Features
- Real-time code execution
- Syntax highlighting and validation
- Drag-and-drop function library
- Complete Deluge function documentation
- Error highlighting and debugging
- No account registration required

### 🎯 Best Practices
- Start with simple scripts from the `basic/` folder
- Test one function at a time
- Use `info` statements for debugging
- Save your work locally after testing
- Document your results in the `tests/` folder
